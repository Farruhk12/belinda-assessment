# Синхронизация Belinda Assessment с Google Sheets

## Нужно ли обновлять скрипт?

**Да.** Текущий скрипт не сохраняет все поля, которые использует приложение. Без обновления часть данных будет теряться.

## Что сохраняется через скрипт

Приложение отправляет данные на скрипт через `syncToSheets()` в `StoreContext.tsx`:

| Действие | Лист | Когда вызывается |
|----------|------|------------------|
| addQuiz / updateQuiz | Quizzes | Создание/редактирование шаблона |
| addSession / updateSession | Sessions | Запуск/редактирование сессии |
| saveResult / updateResult | Results | Прохождение теста, проверка ответов |
| addEmployee / updateEmployee | Employees | Создание/редактирование сотрудника |
| addPosition | Positions | Добавление должности |
| addAssignment / deleteAssignment | Assignments | Назначение теста, повторный запуск |

## Как обновить скрипт

1. Откройте [Google Apps Script](https://script.google.com) и выберите проект Belinda Assessment.
2. Замените содержимое `Code.gs` на код из `google-apps-script/Code.gs`.
3. Сохраните и разверните заново (Deploy → Manage deployments → Edit → Version: New version).
4. После развёртывания вызовите `setup()` вручную (Run → setup), чтобы добавить новые колонки в существующие листы.

## Что будет без обновления

- **passThreshold** — проходной балл не сохранится, везде будет 60%.
- **tags** — теги шаблонов не сохранятся.
- **violations, violationDetails** — данные о нарушениях не сохранятся.
- **questions** в Results — структура вопросов при проверке может теряться.
- **isRetake** — флаг повторного назначения не сохранится.
